# Studio attribution

The `/studio` shell is original Milimo Video code. Its interaction patterns were
informed by the Apache-2.0 licensed **Kubona** project:

- infinite board camera (pan/zoom), level-of-detail presentation, minimap, and
  the accessible list equivalent
- command-dock layout with context chips and plan-before-apply flow

No Kubona source files, quantum-domain models, assets, or trademarks are copied.
Only general interaction patterns were reimplemented against Milimo's project
model.
